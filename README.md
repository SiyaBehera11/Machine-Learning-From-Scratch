# Machine Learning From Scratch 🚀

A hands-on journey into Machine Learning using Python and NumPy.

This repository documents my journey of understanding and implementing Machine Learning algorithms from scratch, focusing on the mathematics behind them, gradient derivation, optimization techniques, and practical implementation.

Rather than simply using pre-built ML libraries, the goal is to understand what's happening behind the algorithms and build them step by step.

## 🎯 Objectives

- Understand the mathematical foundations of Machine Learning.
- Implement algorithms from scratch using NumPy.
- Derive gradients and understand how gradient descent works.
- Experiment with different datasets and optimization techniques.
- Progress from fundamental ML algorithms to more advanced Deep Learning concepts.

## 📚 Topics & Implementations

### 1. Regression
- Linear Regression using NumPy
- Gradient Descent from scratch
- Mean Squared Error (MSE)
- Polynomial Regression
- Nonlinear relationship modelling

### 2. Classification
- Logistic Regression using NumPy
- Sigmoid activation function
- Binary Cross-Entropy Loss
- Gradient Descent for classification

### 3. Upcoming Implementations
- Binary classification on MNIST (0 vs 1)
- Multiclass classification using Softmax
- Categorical Cross-Entropy
- Neural Networks from scratch
- Backpropagation

## 🛠️ Tech Stack

- **Python** – Core programming language
- **NumPy** – Numerical computations and algorithm implementation
- **Matplotlib** – Data visualization
- **Jupyter Notebook** – Experimentation and documentation
- **Git & GitHub** – Version control

## 🧠 Learning Approach

Each implementation focuses on:

1. Understanding the mathematical intuition.
2. Deriving the necessary equations and gradients.
3. Implementing the algorithm using NumPy.
4. Training models using gradient descent.
5. Evaluating predictions and analyzing results.

## 📈 Progress

This repository is a work in progress. New implementations, experiments, and improvements will be added as I progress through Machine Learning and Deep Learning.

## 🎯 Final Goal

To develop a strong understanding of Machine Learning and Deep Learning fundamentals by implementing algorithms from the ground up and gradually progressing towards building more complex AI systems.
